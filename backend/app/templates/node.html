{{ icon('eye') }} Identificar

El LED parpadea rápido 15 s. Útil para encontrar el nodo físico entre varios.

{{ icon('zap') }} Ping

Comprueba que el nodo recibe comandos; responde «pong».

{{ icon('flame') }} Calibrar MQ-4

Calcula R0 en aire limpio durante 20 s. Hazlo con el sensor caliente (3 min encendido) y fuera del biodigestor.

{{ icon('cloud') }} Cero de CO₂

Fija 400 ppm como referencia. El sensor debe llevar 20 min al aire libre; si no, todas las lecturas quedarán desplazadas.

{{ icon('refresh') }} Borrar R0

Olvida la calibración del MQ-4. El metano se mostrará vacío hasta recalibrar.

{{ icon('power') }} Reiniciar

Reinicia el ESP32. Vuelve en unos 10 s; el MQ-4 necesita otros 3 min de calentamiento.
