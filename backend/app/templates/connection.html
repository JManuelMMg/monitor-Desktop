{{ icon('download') }} Usar como aplicación

Ya la estás usando como app

Se abre en su propia ventana, con icono en el menú Inicio, la barra de tareas o la pantalla del móvil. Es la misma app de escritorio, sin instalar nada aparte.

{% call hint('Si no aparece el botón «Instalar»') %}
  • Windows (Edge o Chrome): menú ⋯ › Aplicaciones › Instalar este sitio como aplicación.
  • Android (Chrome): menú ⋮ › Instalar aplicación o Añadir a pantalla de inicio.
  • iPhone / iPad (Safari): botón Compartir › Añadir a pantalla de inicio.
  • La instalación exige HTTPS con el certificado de la Pi aceptado (ver «Certificado» abajo).
{% endcall %}

{{ icon('list') }} Direcciones del servidor

Las mismas que usa la app de escritorio: primero la red local y después la VPN. Si la conexión se corta, la web comprueba las demás y salta a la primera que responda.

{% call hint('¿De dónde salen estas direcciones?') %} Las define el administrador en la Pi con PUBLIC_URLS en /etc/monitor/monitor.env (por ejemplo https://192.168.1.50:8443,https://10.8.0.1:8443). Por seguridad la web solo puede comprobar esas direcciones. Al pasar a otra dirección quizá tengas que iniciar sesión de nuevo: la sesión se guarda por dirección. {% endcall %}

{{ icon('shield') }} Desde fuera de casa

  1. 1Instala la app oficial de WireGuard (Windows, Android o iOS).
  2. 2Pide al administrador tu archivo de túnel o el código QR (wireguard.sh add <equipo> en la Pi).
  3. 3Activa el túnel y abre esta misma app: la dirección de casa también funciona por la VPN.

{{ icon('key') }} Certificado

La Pi usa un certificado propio. Para que el navegador o la app no muestren advertencias, importa su CA una vez en cada equipo:

  • {{ icon('cpu') }}Windows: desktop\instalar_ca.ps1 -Ruta .\ca.crt
  • {{ icon('cpu') }}Android / iOS: abre ca.crt e instálalo como certificado de CA.
